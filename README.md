# THE ARANYA PROMENADE — Biophilic Luxury Retail Sanctuary | Bengaluru

An ultra-luxury, biophilic real estate commercial mall landing page and dynamic modular CMS interface located in Bengaluru’s premier luxury corridor (Outer Ring Road / Whitefield luxury belt).

Built strictly with artisanal frontend craftsmanship — **Zero AI Slop / Zero Generic Templates** — featuring custom WebGL liquid fluid displacement physics, Three.js 3D spatial floor plan exploration, an in-browser live CMS studio for mall management, and a tenant leasing RFP calculator.

## ✨ Key Features & Interactive Innovations

### 1. 3D WebGL Liquid Fluid Displacement Hero
- **Custom GLSL Shader & Three.js Canvas**: Interactive liquid ripple displacement reacting to cursor trajectory, velocity, and touch gestures.
- **Dynamic Physics & Specular Refraction**: Chromatic aberration (RGB light dispersion), liquid caustics, and ambient surface tension waves.
- **3 Material Shaders**:
  - *Verdant Living Glass* (Biophilic emerald and forest water caustics)
  - *Obsidian Liquid Mercury* (High-sheen liquid chrome)
  - *Champagne Aurum* (Brushed gold liquid metal shimmer)
- **Floating 3D Droplets**: 3D specular physical spheres that bob and repel away from user interaction.
- **Real-Time Telemetry**: 60 FPS performance monitor.

### 2. Interactive 3D Spatial Mall Explorer
- **Three.js 3D Isometric Navigator**: Real-time rendering of the 4 mall levels:
  - **Level 0 — The Living Ground**: Couture flagships (Bottega Veneta duplex, Sabyasachi Royal Atelier, Cartier Maison) & 80-year-old preserved ficus trees.
  - **Level 1 — The Glass Pavilion**: Haute Horlogerie (Rolex by Ethos), Apple Biophilic Glasshouse, Raw Mango, Dyson VR Lab, Bang & Olufsen Acoustic Studio.
  - **Level 2 — The Canopy Terraces**: Al fresco gastronomy (Trattoria Aranya, Baoshuan Cantonese Sky Terrace, Blue Tokai Reserve Roastery).
  - **Level 3 — The Oasis Skydeck**: PVR Director’s Cut Laser IMAX with South India’s first Onyx Cinema LED screen & Six Senses Urban Day Spa.
- **Interactive Orbit Camera**: Drag to rotate, smooth spring interpolation, tilt angle limiters.
- **Kinetic Rainwater Waterfall**: Vertical falling particle system running in the central atrium.
- **Interactive Store Pins & Pavilions**: Glowing 3D store footprints and floating pins synchronized with the active floor plan.

### 3. Dynamic Modular CMS Studio (In-Browser Live Admin)
- **Direct Live Editing**: Add new stores/maisons, edit existing unit allocations, square footage, operating hours, and lease badges.
- **Live State Updates**: Landing page reflects newly added or edited stores immediately without page refresh.
- **JSON Data Export**: 1-click export of the active tenancy database as a clean JSON schema ready for headless CMS integration (Strapi, Sanity, Contentful).
- **Reset to Curated Baseline**: Quick reset button to restore the 18 curated international & Indian luxury houses.

### 4. Curated Luxury Store Directory
- **Deep Search**: Instant query matching by brand name, category, unit number, or keywords.
- **Multi-Level & Category Filtering**: Filter across 7 luxury categories and floor levels L0–L3.
- **Store Detail Modal**: High-resolution gallery, curator's architectural notes, VIP service amenities (VIP fitting lounges, private valet drop-off, in-store champagne bars), and interactive VIP appointment booking form with confetti celebration.

### 5. Interactive Retailer Leasing & ROI Calculator
- **Footprint Selector**: From 250 sq.ft artisanal kiosks to 12,000 sq.ft anchor grand maisons.
- **Telemetry Projections**: Targeted weekly footfall exposure (145k+ high-net-worth individuals), average customer dwell time (148 minutes vs 65-min conventional mall benchmark), and solar microgrid energy savings.
- **Instant RFP Submission**: Direct developer leasing dossier request form.

### 6. Sensory & Operational Touchpoints
- **Live Bengaluru IST Clock**: Real-time clock synchronizing with Indian Standard Time (`Asia/Kolkata`).
- **Atrium Environmental Telemetry**: Real-time Bengaluru temperature (24°C) and Atrium AQI index (38 • Pure Purified Air).
- **Web Audio API Biophilic Soundscape**: Synthesizes a gentle stream murmur and 432Hz harmonic drone using native browser Web Audio oscillators and filtered noise (zero external MP3 files required).

## 🚀 Running Locally

```bash
# Clone or navigate to the repository
cd /mnt/personal/projects/demo1

# Install dependencies (already installed)
npm install

# Run the development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

Server will be running at `http://localhost:3000/`.
